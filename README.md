# 汀沿巡查 · 公共座椅漏查估算

汀沿养护站的 7 人班组负责滨江步道的座椅清点与维修。过去两支队把照片交到 `沿江座椅盘点-11月.xlsx` 汇总。领班难以发现两轮记录里同号复记，也不好区分确实漏查与资产迁移，低重合区段常被迫照单派发。系统把区段、两轮带编号的发现、补巡优先级接起来，生成值班组派发表。

| 角色 | 页面 | 权限与动作 |
|---|---|---|
| `analyst` 路线协调员 | 巡查区段、双轮发现清单、漏查估算、复点抽样 | 管理区段、核对双轮标签、创建估算与分层抽签、回传复点 |
| `manager` 巡查领班 | 补巡派发 | 协调员权限，另可签核计划、查看审计 |
| `viewer` 养护观察员 | 五个模块 | 查阅记录与导出派发表 |

## 周末工作剧本

1. 07:20 查看 `NOV21-BENCH` 岸段范围，分别派出 A、B 两组，期间分开记录。
2. 08:05 收到 A 轮柳渡段 30 张有效座椅编号。
3. 09:15 收到 B 轮柳渡段 26 张有效编号，18 个标签同号。
4. 09:30 检查芦廊段 `BANK-04-S017` 的 B 轮待核照片。确认同一实物后在台账查验。
5. 09:40 标记船坞段受围挡影响，石桥段仅 1 个重合标签，均作为人工复核项。
6. 10:00 确认两轮独立，设最少 5 个匹配。柳渡段实见 38 个编号，估计总量约 43.05，漏查约 5.05。
7. 10:15 领班签核「午班优先巡柳渡段」，持久留存排程意见。
8. 10:30 养护员下载 CSV 发给午班，现场发现用于下一轮新的批次。

## 计算口径

按批次、区段、轮次和唯一实物标签记录。同一轮的同一标签重复写入会阻断；跨轮合并以交集 `m` 和并集计算。Chapman 点估计为 `(nA+1)(nB+1)/(m+1)-1`，使用 Chapman 方差公式。漏查估计为总量减实见，并按分段结果排序。已确认独立样本、区段封闭、标签全部核对且重合数达到门槛后才输出数值。共享巡查路径、材质或位置导致可见性不均会偏置估计。项目使用固定模拟清单，快照保留计算时口径；建议按报告复查，派发表在系统中签核后可下载，现场派单仍由班组执行。

## 复点抽样口径

两轮巡查后，养护组可抽若干区段全数复点，回推整批漏查：

1. **锁定实见编号**：建单时按巡查批次快照每段全部 `verified` 资产编号，待核标签不进锁定清单；快照随批次持久化。
2. **按两岸分开抽签**：以区段 `bank` 字段分层，层内不放回简单随机抽样，使用固定随机种子（可复算）。每层样本量由协调员指定，不得超过该岸区段数。
3. **按抽中概率推算**：层内抽中概率 `π = n_h / N_h`；段漏查 `m_i = max(0, 复点总数 − 锁定实见数)`，Horvitz–Thompson 层估计 `N_h · m̄_h`，方差 `N_h² · (s²/n_h) · (1 − n_h/N_h)`。有缺测段时仅有效复点段参与，等效样本量取有效段数 `r_h`。整批为各层之和，单侧上限 = 点估计 + `t(置信水平, r_h−1) · √方差`。
4. **进不去的区段留在样本里**：标记 `blocked` 并记录原因，不剔除、不另抽替代段，其缺测影响在结果中明示。
5. **算不出上限就明说**：某层无有效复点段、或仅 1 个有效段（自由度 0）时，该层与整批上限返回 `null`，页面与指标中写明“上限无法计算”；此时仍给出点估计。
6. **重跑不改换已抽中区段**：重跑只允许加大每岸样本量；同种子复算结果一致，换种子扩充时原有抽中段必须保留，缩量或会丢失旧段的抽签返回 409/422。
7. **现场回传与批次对账**：回传编号数必须等于复点总数；复点集合缺少任一锁定编号即把该段置为 `suspended`（挂起），挂起段不参与推算并列出缺失编号；回传中多出的编号视为现场补出的漏查。同段结论唯一，重复回传阻断。
8. **补巡单页面**：`补巡派发` 页顶部展示最近抽样批次的整批漏查点估计、上限与缺测影响；完整分层、对账与回传表单在 `复点抽样` 页（路由 `#sampling/:id`）。

新增表 `audit_sampling_plans`、`audit_recount_returns`，全新库由 `create_all` 自动建立，既有 MySQL 数据卷的等价 DDL 见 `backend/migrations/README.md`。种子脚本会生成一个含“已复点 + 进不去”样本的演示批次。
